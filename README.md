# 🏫 Classroom Roster — Student Management System

A full-stack web application for managing student information, attendance, and grades. Built with Node.js, Express.js, JSON Server, JWT Authentication, and Vanilla JavaScript.

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Runtime | Node.js |
| Web Framework | Express.js |
| Database | JSON Server (db.json) |
| Authentication | bcryptjs + JWT |
| Frontend | Vanilla JavaScript + HTML5 + CSS3 |
| HTTP Client | fetch() API |
